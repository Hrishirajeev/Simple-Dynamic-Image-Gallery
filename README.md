# Simple-Dynamic-Image-Gallery
Responsive image gallery built with React + Vite.

## Features

- Dynamic image cards using `map()`
- Reusable React components
- Props and component separation
- Responsive CSS Grid
- Add images from your device
- Delete images
- Mobile navigation
- About section and footer

## Tech Used

- React
- Vite
- JavaScript
- CSS

## Run Locally

```bash
npm install
npm run dev
